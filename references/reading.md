# 读图与关系描述库

先看完整画面，再按需要看局部。记一句画意、媒介与笔触、已有事件、光/空气、主次、空间、保护区域。库存对象的名称只帮助观察，不自动决定动画。主导动态可由单一动作承担，也可由光、空气、水面等分布变化承担。先判断原画哪些边界清晰、哪些有意虚化或与底色交融，再决定能否分离；不要等切层后才判断媒介。

一条可复用描述记录：可见线索、适用条件、原因、承载者、连接与材料、响应/后果/恢复、可动范围、隐藏背景需求、工具能力、反例与证据。坐标、角度、数量和时刻留在job。对实际采用的每种原因，补记作用范围、关键承载与连接、预期响应和静止依据；只记录会改变机制判断的结构，不逐点登记。先由画意与材料判断响应，再选择提取方法，不让提取难易反过来决定哪些对象可以响应。

| 关系 | 应推导什么 | 容易误用的地方 |
|---|---|---|
| 外力与柔性载体 | 固定端/自由端、刚度、重量、传播和恢复 | 不同材料全用同一正弦；自由端动而连接断开 |
| 附着与承载 | 共同空间和运动、允许的相对自由度、接触点 | 共享时序当连接；所有附着物都冻结相对动作 |
| 悬挂与承重 | 支点、绳长、松弛、单/多支撑及画外延续 | 见悬挂就单摆；共同受力就整体刚体 |
| 接触与反射 | 原体运动、接触区域、镜像几何和介质响应 | 倒影复制原体同一平移；动画水面代替联动 |
| 遮挡与显露 | 前后归属、联合运动范围、连续纹理和结构线 | 跨背景对象漏选；补底归到移动前景 |
| 笔触与所画状态 | 笔触表现物体本身，还是它的运动、光或透明叠色；状态笔触在原位已承载动态；可动的形取物体本体，或画中同类元素的静止形 | 把拖痕、速度线当实物平移，得到慢速移动的模糊 |
| 透明叠色 | 观察色＝颜料×底色；离开原底的元素用透射关系从原底估颜料本色，或参照画中画在中性底上的同类元素 | 按不透明叠加解出的前景色在笔触核心仍是叠色，换底后异色 |
| 同类元素 | 飘飞与已落地、复制件与原件读作同一种东西：颜色、形态、尺度、来源与去向一致 | 只看单件是否好看，不与画中同类比对 |
| 光与空间 | 光源/遮挡物、受光面、方向、传播和固定拍摄痕迹 | 任意滤镜当场景光；画框反光跟画内天气走 |
| 动态主导与注意力 | 动作或分布变化、支持响应、静止骨架、动态避让 | 强求单一主角或大动作；运动数量当生命感；静态中心避让代替完整路径 |

同一原因不要求所有对象同幅、同步或持续响应。刚性连接、重量、固定端、遮蔽及作用范围外的部分可以支持静止，局部变化也可以微小、不均匀或间歇；不设自由端一律最大或每个细节独立可察觉的通则。主次排序能说明表现强弱，不能单独解释已选机制中的必要响应为何缺失。画面依据不足与工程未完成应分别记下，不能统一改称审美静止。

这些关系不保证当前工具都能表达。场景需要复杂约束或反射时，先核实现，再扩展或明确该部分未完成。平面构图、厚涂、水彩留白、线刻与透明画法应分别读其可见结构，不能仅凭风格名称决定能否有空间或局部运动。

画意本身安静、或没有单一承载者时，按画意选择幅度，以目标显示尺寸下可察觉核可读性；记下“因画意而小”的画面依据。有明确主体动作时仍落实该动作，不能将补底或结构缺陷改称安静。真正不可兼得的取舍按[正文第8步](../SKILL.md)，工程未完成不进入美学让步。
