# 检验画面与运行行为

确定性捕获适合比较同一事件；连续播放用于判断速度、停顿、重复与注意力。只能看单帧或帧条时，将节奏标为未审。不要从运动面积、像素变化或通过数量推导美学通过。

## 1. 捕获入口

以下命令从implementation目录运行。先用`--help`核实参数；所有自建Chrome加`--disable-features=MacAppCodeSignClone`，退出时关闭浏览器并删除自己创建的临时profile。

```sh
node scripts/capture.mjs JOB/out/index.html --out JOB/check --every 0.5 --duration 12
node scripts/capture.mjs JOB/out/index.html --out JOB/check/corners --times 3,5,7,9 --pointer corners:2-10
node scripts/capture.mjs JOB/out/index.html --out JOB/check --video 16
python3 scripts/picture.py sheet FRAMES --out JOB/check/sheet.jpg --motion
```

时间、时长、尺寸均按事件选择；以上仅示范语法。要近看某个动作，先用 `--channels blink,tilt,…`（各通道范围与峰值时刻）和 `--track "layer:x,y;…"`（某点最大位移及时刻）密集取样找时刻，再在那几个时刻取高清帧；释放元素用 `picture.py inspect work --layer id --pieces` 逐件看，静止误差看 `work/review/rest-residual.png` 与 `layers.json` 的 `rest_clusters`。快速闭眼、接触和跳变需更密采样；半秒帧可能完全漏掉。记录seed、时间、输入、相机、视口、DPR和版本。实际执行器不支持该捕获路径时，用同一播放器的seek/advance/snapshot接口捕获，保留等价参数，不能假报已运行。

## 2. 分开的检查

| 检查 | 做法与证据边界 |
|---|---|
| 原图回退 | 进入pause/reset或减少动态，等原图完成解码，抓无损原生尺寸图，与规范工作原图比较。单独核绘制是否停止 |
| 第零合成帧 | seek(0)后抓PNG；其合成误差与原图回退分开记录。默认PNG编码不保证图层合成零差 |
| 分层不变量 | 对比求解前后alpha、消耗的底板及零alpha处的观测原图；alpha不得因底板误差增加，底板不得被前景残差写回，protect内保持背景归属。代码检查只证明这些约束，不证明遮挡归属正确 |
| 软边与供体 | 将alpha、前景色及补底分别检查；在浅、深和相关实际底色上看边缘。供体的整个正方形patch（含角）须落在所属背景面的允许区，每层金字塔均如此；中心合法不够 |
| 主导动态 | 看动作完整起始、峰值与恢复，或分布变化的全程和变化最大处；核其意义和目标尺寸可察觉性，不设统一像素百分比 |
| 预期响应 | 对照读画时已选原因、作用范围与关系，核关键约束处、运动传递处及代表性可动区域；区分视差、随承载者运动与相对运动，并核静止依据。整块有位移不能证明局部机制成立；不要求所有细节独立可察觉 |
| 联合显露 | 主体、父体、镜头同时到允许范围边缘；检查背后旧轮廓、随动底色、空洞与背景面归属 |
| 接触及参考系 | 检查支点、握持、承重、附着及文字所属载体。共用时序不等于几何连接 |
| 笔触与轮廓 | 对比宽度、方向、肌理和轮廓；核原本虚化的边仍虚化，未为分层造硬边；看原生局部及实际显示尺寸 |
| 松散元素 | 核完整旋转/缩放轮廓及相机投影，避开动态叙事焦点；region并非自动屏幕避让 |
| 释放元素逐件 | 每个会离开原位的部件单独放在深、浅及它将经过的实际底上：只含该物体、本体完整（不只是尾迹碎片）、没有夹带邻近线条或原底色；颜色为颜料本色并与画中同类一致；看复制件同屏的相同形状数与重复频率。总览和帧条会掩盖单件缺陷 |
| 节奏 | 能播放时看完整事件与事件间隔；若只得帧条/变化曲线，记录顺序和趋势，节奏仍未审 |
| 嵌入行为 | 手机/桌面尺寸、减少动态、暂停重播、离屏返回、快速切图、销毁中加载、错误回退 |

`picture.py diff A B`默认拒绝尺寸不符。确需重采样比较时显式`--resize`，报告将标记；不能把这份差图称原生像素等同。透明输入的比较须保留alpha，并在相关底色上检查显露。

`plate_solve`中的alpha增量、新增支撑及底板改写诊断应符合固定alpha/底板合同；`rest_residual`必须保留，不能为降低它扩大覆盖、污染背景或用不透明亮边遮住错误。颜色键匹配分数、matte颜色线拟合可靠性、`fill.confidence`和物理alpha不是同一量。`matte`在样本不足或拟合不可靠时不能证明边缘已分离，`regions`也只检查作者的分区是否完整、无重叠；两者都不能自动确认真实隐藏表面。低rest误差、缓存命中、声明范围足够均不能替代移动后检查。

## 3. 从症状回到原因

| 看到什么 | 优先排查 |
|---|---|
| 整体有位移但必要的局部响应缺失 | 分别核是否遗漏响应规划、所需结构未完整提取、绑定或权重错误、运动模式不适合，或目标尺寸下不可读；先定位原因，不直接加大全局幅度 |
| 跨背景的同一对象缺片或带底色 | 对象是否完整；每种相邻背景是否有适合的提取方法；源层和补底是否归到正确面 |
| 原位置残影或随动光边 | 分开核alpha是否遗漏或膨胀、前景色是否带原底色、供体是否跨面/越过avoid、plate是否藏有旧轮廓，最后核采样；不以增大spread或提高confidence直接判修好 |
| 笔触拉宽或轮廓变胖 | 变换是否适合媒介；网格、权重、刚柔连接及采样；不先默认缩幅 |
| 子部件滑动 | 运动变换、父深度、挂载次序与支持能力；不要只查是否引用同一channel |
| 闭眼留下点或薄线 | 原生尺寸、显示采样、闭合几何和叠加动作；逐帧隔离，不凭某个静态点认定根因 |
| 动态与空间过弱 | 主导动态是否表达画意、机制是否有效、目标尺寸是否可察觉；核因画意而小的依据与是否以小遮错，不以参数非零算成功 |
| 所有东西机械同步 | 支撑、材料、因果传播与事件组织；持续变化本身并非错误 |
| 飘飞元素换了底就异色，或带暗边、浅边 | 叠色当成了本色（用 `pigment`）；软边带着原底；选区夹带邻近线条 |
| 移动的东西穿过明暗交界却亮度不变 | 没有 `lightMap`/`relight`；光照图按背景深浅推出而不是按物体所在处的光 |
| 散落元素像棍子一样整片平移 | 把表现运动的笔触当成物体；为压住自转等症状而加的约束 |
| 元素离开后原位留下淡轮廓或平滑的形状 | 整体离开的层没有连软边一起补；有纹理的表面用了平滑填充；描边留在了底板上 |

一个改动只重验受影响依赖，保留关键旧反例。调大幅度或数量后，受放大的机制重新逐件验收：数量与幅度会把单件缺陷和重复一起放大。对通用规则，用未参与调参且结构不同的画面实际运行；文字演练仅说明规则理解。失败可回退原图并如实记录，但所要求的动画仍未完成。

若已尝试补足模型和换表达仍出现真冲突，核第1步的画意承载项及第8步记录的公开让步。接触、支撑、遮挡和原画笔触不得因让步受损；两项都承载画意或须改写画意时才提请用户决定。这里只核取舍是否被执行，不能用取舍记录替代画面证据。
